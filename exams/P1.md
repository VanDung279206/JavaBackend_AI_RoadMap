# Kiểm tra Phase 1 — Danh mục khóa học

Tự viết `Course(id,title)` và catalog trong bộ nhớ. Có add, list, search không phân biệt hoa/thường, remove. Title được strip và gộp khoảng trắng. ID dương; trùng ID bị từ chối và không làm mất bản cũ. Search trả ID tăng dần. Không sửa class lời giải cũ để nộp.

Dữ liệu mới: `(21," Java   Core ")`, `(7,"SQL Basics")`, `(12,"java Backend")`.

Yêu cầu: tìm ` JAVA `; thêm ID=21 lần hai; xóa ID=999; xóa ID=7; liệt kê lại. Viết test title trắng, catalog rỗng, danh sách trả về không cho sửa nội bộ. Giải thích lựa chọn Map và khác biệt parameter/argument.

Rubric: chức năng 40; biên và không ghi đè 25; test bắt được lỗi 15; giải thích độ phức tạp và cấu trúc 10; tiếng Anh/README 10. Bắt buộc: trùng ID không ghi đè; tự chạy được.
