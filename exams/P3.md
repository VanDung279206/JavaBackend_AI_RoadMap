# Kiểm tra Phase 3 — API ghi chú

Tạo API `/notes` với owner, title và body. Owner lấy từ principal. Title 1–80 ký tự sau strip; body không null, tối đa 10000 ký tự. Có create/get/list/update/delete; list theo createdAt DESC,id DESC; page>=0,1<=size<=50.

Fixture: An tạo note A, Bình tạo note B. An sửa A rồi đọc lại; Bình đọc/sửa/xóa A phải bị từ chối theo hợp đồng 404. Input title trắng, size=0, body null là 400. Tạo note phải đồng thời ghi audit; lỗi audit làm rollback note.

Nộp migration, DTO, controller/service/repository, test HTTP và PostgreSQL. Tắt/mở app với cùng database rồi đọc lại A.

Rubric: API/DTO 25; lưu trữ/migration 20; owner và input 25; transaction/test 20; README/tiếng Anh 10. Bắt buộc: không tin owner từ client; audit failure rollback; dữ liệu sống qua restart khi dùng PostgreSQL.
