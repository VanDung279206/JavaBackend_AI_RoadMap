# Đối chiếu Phase 1

- Sau chuẩn hóa: `Java Core`, `SQL Basics`, `java Backend`.
- Search ` JAVA ` trả IDs `[12,21]`.
- Thêm lại 21 phải ném lỗi; bản 21 vẫn là `Java Core`.
- Remove 999 trả false; remove 7 trả true. Nếu list theo thứ tự thêm như Catalog tham chiếu: `[21,12]`; search vẫn phải theo ID tăng dần.
- Title trắng/ID<=0 bị từ chối. Trả `List.copyOf` hoặc bản sao tách rời để client không sửa kho nội bộ.

Lời giải cấu trúc: dùng Map<Long,Course>; `putIfAbsent`; tìm kiếm duyệt values, lowercase với Locale.ROOT, filter rồi sort. Add/find/remove kỳ vọng O(1); search O(n + m log m) bỏ qua chi phí xử lý chuỗi, m là số kết quả. Nếu dùng list thuần, cần giải thích tìm theo ID O(n).

Đối chiếu thuật toán tại `practice/solution/JavaCoreLab.java`, nhưng phải tự đổi entity và dùng dữ liệu đề mới. Bài console có mẫu tại `projects/catalog-cli/`.
