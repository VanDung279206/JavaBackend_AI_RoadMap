# Đối chiếu Phase 4

| Người gọi | Đọc tài liệu tồn tại | Sửa/xóa | Summary/index |
| --- | --- | --- | --- |
| Chưa xác thực | 401 | 401 | 401 |
| Owner | 200 | 200/204 | 200 nếu input hợp lệ |
| Người khác | 404 | 404 | 404 |

Không chỉ mock service rồi trả 404 cố định: ít nhất một test phải đi qua filter xác thực và service/repository. ApiTest trong app dùng Basic credentials để thử toàn luồng MockMvc; PostgresIT kiểm tra database thật.

Mutation đối chiếu: bỏ `ownerId` khỏi lookup → test người khác phải thất bại; khôi phục → pass. B03 là phiên bản Java thuần để hiểu lỗi, chưa thay thế test HTTP.

Docker phải dùng DB hostname `db` khi app cùng Compose network. Runtime secret qua environment. Compose `.env` không tự trở thành environment của Maven bạn chạy ngoài Compose.

CI: checkout → JDK → dependency cache → unit/HTTP test → PostgreSQL Testcontainers → package. Log cần request ID, path, status, thời lượng; tránh ghi Authorization, password và toàn bộ tài liệu. Mẫu workflow trong repo kiểm tra **bản tham chiếu**, hãy trỏ pipeline bài làm vào đúng bản copy của bạn.
