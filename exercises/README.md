# Bài tập

Đề và lời giải đã được tổ chức tại [phases/README.md](../phases/README.md) và [dsa/EXERCISES.md](../dsa/EXERCISES.md). Thư mục này dành cho bài tự làm của người học; mã lời giải Java tham khảo nằm riêng trong `labs/src/`.

Mỗi bài nằm trong một thư mục riêng, ví dụ `01-document-catalog` hoặc `02-sql-schema`.

README của mỗi bài cần nêu mục tiêu, điều kiện chạy, lệnh chạy, kết quả mong đợi và kết quả đã quan sát. Với bài Java, đặt mã nguồn và cấu hình build ngay trong thư mục bài.

Bài đầu tiên: quản lý danh mục tài liệu trên terminal với thao tác thêm, liệt kê, tìm theo tiêu đề và xóa theo ID. Sau khi hoàn thành phần lưu trong bộ nhớ, bổ sung đọc/ghi tệp.
