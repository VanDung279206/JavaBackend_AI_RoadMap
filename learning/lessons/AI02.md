# AI02 — Kiểm tra đầu ra có cấu trúc

## Mục tiêu và kiến thức trước

Validate schema và ý nghĩa trước khi lưu/sử dụng output.

**Cần biết trước:** AI01; DTO và validation.

## Tình huống

Model có thể trả summary trống hoặc trạng thái ngoài enum. Parse được JSON chưa đủ để coi kết quả hợp lệ.

## Ví dụ chạy được

Lệnh từ gốc repository: `java learning/examples/AI02.java`. Java cần JDK 17+; ví dụ Python dùng thư viện chuẩn.

```java
import java.util.*;
import java.nio.file.*;
import java.util.concurrent.*;

public class AI02 {
    record Output(String summary,String status) {}
    static boolean valid(Output out) { return out!=null && out.summary()!=null && !out.summary().isBlank() && Set.of("ok","insufficient").contains(out.status()); }
    public static void main(String[] args) {
        System.out.println(valid(new Output("Java basics","ok")));
        System.out.println(valid(new Output(" ","ok")));
        System.out.println(valid(new Output("Java","unknown")));
    }
}
```

**Diễn giải từng bước:**

1. Parser thật chuyển JSON thành DTO; ví dụ bắt đầu sau parsing.
2. Kiểm trường bắt buộc, blank và enum thay vì chỉ object non-null.
3. Kết quả sai bị từ chối; không ghi vào DB hay đưa vào tool call tự động. Thêm giới hạn kích thước và nguồn ở bài thật.

**Kết quả:**

```text
true
false
false
```

## Lỗi thường gặp

**Nhận biết:** JSON hợp lệ nhưng thiếu nội dung hoặc field chứa dữ liệu không được phép.

**Cách sửa:** Kiểm schema và luật nghiệp vụ; fallback/thông báo rõ thay vì coi lỗi là thành công.

## Kiểm tra hiểu bài

status=ok và summary hợp lệ có chứng minh mọi câu trong summary đúng không?

Viết dự đoán và lý do trước khi mở đáp án. Thay một đầu vào trong ví dụ, dự đoán lại rồi chạy.
