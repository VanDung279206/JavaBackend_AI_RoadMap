# Bộ bài tập theo phase

Mỗi phase có bốn bài, gồm input/output hoặc tiêu chí đầu ra, gợi ý, lời giải và các lỗi cần kiểm tra. Mã bài ổn định từ P1.1 đến P6.4 để ghi trong issue và nhật ký ôn.

| Phase | Đề | Lời giải |
| --- | --- | --- |
| P1 — Java Core | [EXERCISES.md](01_Java/EXERCISES.md) | [SOLUTIONS.md](01_Java/SOLUTIONS.md) |
| P2 — HTTP và SQL | [EXERCISES.md](02_Http-Sql/EXERCISES.md) | [SOLUTIONS.md](02_Http-Sql/SOLUTIONS.md) |
| P3 — Spring Boot | [EXERCISES.md](03_Spring/EXERCISES.md) | [SOLUTIONS.md](03_Spring/SOLUTIONS.md) |
| P4 — Chất lượng và triển khai | [EXERCISES.md](04_Quality/EXERCISES.md) | [SOLUTIONS.md](04_Quality/SOLUTIONS.md) |
| P5 — Tích hợp AI | [EXERCISES.md](05_AI/EXERCISES.md) | [SOLUTIONS.md](05_AI/SOLUTIONS.md) |
| P6 — RAG | [EXERCISES.md](06_RAG/EXERCISES.md) | [SOLUTIONS.md](06_RAG/SOLUTIONS.md) |

Lời giải có thể là mã Java, SQL, hợp đồng API hoặc thiết kế kiểm chứng tùy bản chất bài. Các đoạn Spring và Docker được ghi rõ điều kiện tích hợp; không được coi là ứng dụng đã triển khai. Bài AI và vector dùng fixture giả lập để tự học có kết quả kiểm tra được.
